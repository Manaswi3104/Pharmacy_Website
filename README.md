# Pharmacy4U – Online Pharmacy Web Application  

## Project Overview  
Pharmacy4U is an **innovative and user-friendly online pharmacy system** that allows users to access medical products and healthcare services in one place.  
The system provides features like medicine search, category-based filtering, user authentication, and product management.  

---

## Tech Stack  

**Frontend:**  
- HTML, CSS, Bootstrap  
- EJS (Embedded JavaScript Templating)  

**Backend:**  
- Node.js  
- Express.js  

**Database:**  
- MongoDB (with Mongoose ODM)  

**Other Tools & Libraries:**  
- Git/GitHub (Version Control)  
- Dotenv (Environment Variables)  
- Multer (File/Image Uploading, if applicable)  
- Express-session (Session Management)  

---

## ✨ Features  
-  **Search Functionality** – Quickly search for medicines by name or category.  
-  **User Authentication** – Secure login and registration system.  
- **Category-based Filtering** – Browse medicines by categories.  
-  **Product Management** – Store and manage product details in MongoDB.  
-  **Responsive UI** – User-friendly design for better accessibility.
